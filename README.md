# БелТрансОйл-Сервис — Astro сайт-визитка

Статический сайт-визитка для B2B-компании, которая занимается сопровождением топливных карт и безналичной заправкой транспорта в Беларуси.

## Запуск

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
npm run preview
```

## Структура

- `src/pages/index.astro` — русская версия
- `src/pages/en.astro` — английская версия
- `src/data/content.ts` — тексты сайта
- `src/components` — секции лендинга
- `src/styles/global.css` — стили

## Что заменить перед публикацией

- телефон
- email
- юридический адрес
- домен в `astro.config.mjs`
- реальные реквизиты компании
- ссылки на политику конфиденциальности и обработку заявок
